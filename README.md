# AutoMagic

AutoMagic is an open-source virtual assistant operations platform for managing clients, projects, tasks, billing, support, AI agents, and training workflows across web, mobile, and desktop.

## Apps

```text
www.automagic.dev       Public website
client.automagic.dev    Client portal
studio.automagic.dev    VA/operator workspace
sandbox.automagic.dev   Training simulator
admin.automagic.dev     Internal admin panel
```

## Stack

